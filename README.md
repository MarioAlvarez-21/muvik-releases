# Muvik

Tu música, descargada y sin anuncios. Muvik es un reproductor de música para Android: pega o comparte un enlace y la canción se queda en tu móvil, con su carátula y su letra.

Este repositorio solo guarda los APK de cada versión. La web con todo lo que hace la app está en **https://muvik-app.vercel.app**.

## Descargar

Descarga la última versión: **[muvik.apk](https://github.com/MarioAlvarez-21/muvik-releases/releases/latest/download/muvik.apk)**

Las versiones anteriores y sus novedades están en [Releases](https://github.com/MarioAlvarez-21/muvik-releases/releases).

## Instalar

1. Descarga `muvik.apk` desde el móvil.
2. Ábrelo y, si Android te lo pide, permite instalar apps desde el navegador o la app Archivos.
3. Toca «Instalar». Si sale un aviso de Play Protect, elige instalar igualmente.
4. Al abrir Muvik, dale «Acceso a todos los archivos»: lo necesita para guardar tus canciones en Música/Muvik.

Para actualizar, instala la versión nueva encima de la anterior, sin desinstalar. Se conservan tus canciones, playlists y ajustes.

## Requisitos

- Android 14 o superior.
- Móvil de 64 bits (arm64).

## Aviso

Proyecto personal sin ánimo de lucro. Descarga solo contenido que tengas derecho a guardar.
